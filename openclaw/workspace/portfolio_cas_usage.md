## 🤖 Optimisation Prompts IA

### Cas #4 : Prompts Marketing E-commerce
**Problème client** : Descriptions produits génériques, taux conversion faible.

**Avant** : 
```
Écris une description pour [produit]
```

**Après** :
```
Tu es un copywriter e-commerce expert en [niche]. 
Écris une description produit pour [produit] qui :
- Hook émotionnel en 1 phrase (douleur → solution)
- 3 bénéfices clients (pas features)
- Preuve sociale intégrée
- CTA urgence douce
Format : 150 mots max, ton [casual/premium], pour cible [avatar].
```

**Résultat** : +35% taux d'ajout panier rapporté par client

---

### Cas #5 : Assistant Rédaction LinkedIn
**Problème client** : Posts IA "robotiques", faible engagement.

**Avant** : 
```
Écris un post LinkedIn sur [sujet]
```

**Après** :
```
Contexte : Je suis [rôle] parlant à [audience]. Mon style : [exemples posts performants].

Écris un post LinkedIn sur [sujet] avec :
- Hook controversé ou contre-intuitif (ligne 1)
- Histoire personnelle ou observation (3-5 lignes)
- Insight actionnable (la leçon)
- CTA engagement (question ouverte)

Contraintes : 150 mots max, phrases courtes, sauts de ligne fréquents, 0 emoji sauf 1 en fin.
```

**Résultat** : Engagement x3 sur les posts suivants

---

### Cas #6 : Prompts Analyse Données
**Problème client** : ChatGPT donnait des analyses superficielles de datasets.

**Framework livré** :
```
Tu es un data analyst senior. Voici un dataset [format].

Analyse en 4 étapes :
1. PATTERNS : 3 tendances principales avec % précis
2. ANOMALIES : Outliers et explications possibles
3. CORRÉLATIONS : Relations entre variables (attention causalité ≠ corrélation)
4. RECOMMANDATIONS : 3 actions business basées sur les données

Format : Bullet points, chiffres précis, niveau de confiance pour chaque insight.
```

**Résultat** : Analyses actionnables en 1 prompt vs 5+ itérations avant

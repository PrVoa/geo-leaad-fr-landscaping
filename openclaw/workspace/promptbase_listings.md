## PROMPT 1: Business Email Generator Pro

### Basic Info
**Title:** Business Email Generator Pro — Any Situation, Any Tone
**Price:** $2.99
**Category:** Business
**Model:** GPT-4 / GPT-3.5

### Description
Generate perfect professional emails in seconds — cold outreach, follow-ups, negotiations, apologies, and more.

This prompt creates context-aware emails that:
✅ Match your exact situation
✅ Adapt to any tone (formal, friendly, urgent)
✅ Include persuasive CTAs
✅ Stay concise and professional

**Perfect for:**
- Sales professionals
- Freelancers
- Entrepreneurs  
- Anyone who writes emails

**Output includes:**
- Complete email ready to send
- Subject line suggestions
- Alternative versions if requested

Stop staring at blank screens. Get emails that get responses.

### Prompt
```
You are an expert business communication specialist. Write a professional email based on these inputs:

EMAIL TYPE: [cold outreach / follow-up / proposal / negotiation / apology / thank you / announcement / request]

CONTEXT: [Describe the situation - who you're writing to, what happened, what you need]

TONE: [formal / professional-friendly / casual / urgent / empathetic]

KEY POINTS TO INCLUDE:
- [Point 1]
- [Point 2]
- [Point 3]

DESIRED OUTCOME: [What action do you want the reader to take?]

LENGTH: [short (under 100 words) / medium (100-200 words) / detailed (200-300 words)]

Create an email that:
1. Opens with a hook relevant to the reader
2. Clearly states the purpose
3. Provides necessary context without rambling
4. Ends with a clear, specific call-to-action
5. Uses appropriate formality and warmth

Also provide:
- 2 subject line options
- 1 alternative version with slightly different approach
```

### Example Output Preview
"A well-crafted cold outreach email with subject line options that demonstrates professional tone and clear value proposition..."

### Tips for Buyers
- Be specific in the CONTEXT field for best results
- Include relevant details about your relationship with the recipient
- Works great for email sequences (request "email 1 of 3" etc.)

## PROMPT 2: E-commerce Product Listing Optimizer

### Basic Info
**Title:** Product Listing Optimizer — Amazon, Etsy, Shopify
**Price:** $3.99
**Category:** Marketing
**Model:** GPT-4 / GPT-3.5

### Description
Transform bland product listings into high-converting sales copy that ranks AND converts.

This prompt optimizes your listings for:
✅ SEO keywords (platform-specific)
✅ Conversion-focused copy
✅ Benefit-driven bullet points
✅ Emotional hooks that sell

**Works for:**
- Amazon / Amazon FBA
- Etsy
- Shopify
- eBay
- Any e-commerce platform

**Output includes:**
- Optimized title (keyword-rich + click-worthy)
- 5 benefit-focused bullet points
- Compelling description
- Backend keywords suggestions
- A/B test variations

Used by sellers doing $10K+/month. Now it's your turn.

### Prompt
```
You are an e-commerce copywriting expert who specializes in high-converting product listings.

PRODUCT: [Product name and basic description]
PLATFORM: [Amazon / Etsy / Shopify / eBay / Other]
TARGET CUSTOMER: [Who buys this? Demographics, psychographics]
MAIN KEYWORDS: [List 3-5 keywords you want to rank for]
COMPETITORS: [Optional - paste competitor listing or describe what they're doing]
UNIQUE SELLING POINTS: [What makes this product different/better?]

Create an optimized listing with:

1. TITLE (platform-optimized):
- Include primary keyword naturally
- Highlight main benefit
- Stay within character limits ([Amazon: 200 chars / Etsy: 140 chars / adjust per platform])

2. BULLET POINTS (5 total):
- Start each with a BENEFIT, not a feature
- Include relevant keywords naturally
- Use power words that trigger emotion
- Format: BENEFIT HEADLINE: Supporting details with specifics

3. DESCRIPTION:
- Open with emotional hook addressing customer pain point
- Paint a picture of life WITH the product
- Include social proof phrases
- End with urgency/CTA
- Weave in secondary keywords

4. BACKEND KEYWORDS (if applicable):
- List of additional keywords for search indexing
- No duplicates from title/bullets

5. A/B TEST VARIATION:
- Alternative title option
- Alternative first bullet point
```

### Example Output Preview
"A fully optimized Amazon listing for a yoga mat including SEO-rich title, 5 benefit-driven bullets, emotionally compelling description..."

### Tips for Buyers
- Research competitor keywords before using
- Test both title variations
- Update listings monthly with this prompt for fresh optimization

## PROMPT 4: Interview Question Predictor

### Basic Info
**Title:** Interview Question Predictor + Answer Framework
**Price:** $2.99
**Category:** Career
**Model:** GPT-4 / GPT-3.5

### Description
Know EXACTLY what they'll ask before your interview — and how to answer.

This prompt analyzes any job description and generates:
✅ Likely behavioral questions (with STAR answer frameworks)
✅ Technical/skill-based questions
✅ Curveball questions to prepare for
✅ Questions YOU should ask them

**Stop being caught off guard.** Walk into every interview prepared and confident.

### Prompt
```
You are an expert interview coach who has prepped thousands of candidates for competitive roles.

JOB DESCRIPTION:
[Paste the full job description]

MY BACKGROUND (optional but helps):
[Brief summary of your experience and any potential "red flags" to address]

Analyze this role and generate:

1. BEHAVIORAL QUESTIONS (10):
- Questions they're likely to ask based on the role requirements
- For each question, provide:
  * The question
  * What they're really testing
  * STAR framework outline for a strong answer

2. TECHNICAL/SKILL QUESTIONS (5):
- Based on required skills listed
- Include suggested approach for each

3. SITUATIONAL QUESTIONS (5):
- "What would you do if..." scenarios relevant to this role
- Include key points to hit in your answer

4. CURVEBALL QUESTIONS (3):
- Unexpected questions that might come up
- How to handle each gracefully

5. RED FLAG QUESTIONS (if applicable):
- Questions they might ask about gaps, job changes, lack of experience
- Suggested reframes

6. QUESTIONS FOR THEM (5):
- Smart questions that show you've done research
- Questions that help you evaluate if this role is right for you

Format each section clearly. Prioritize the questions most likely to be asked for this specific role.
```

### Tips for Buyers
- Paste the FULL job description for best results
- Include your background for personalized red flag handling
- Review the night before your interview

## PROMPT 5: ATS Resume Scanner

### Basic Info
**Title:** ATS Resume Scanner — Check Your Resume Like HR Software Does
**Price:** $2.99
**Category:** Career
**Model:** GPT-4 / GPT-3.5

### Description
75% of resumes are rejected by ATS before a human sees them.

This prompt scans your resume like Applicant Tracking Systems do and tells you:
✅ Your ATS compatibility score
✅ Missing keywords
✅ Format issues that cause rejections
✅ Specific fixes to improve your chances

**Stop applying blind.** Know exactly why your resume isn't working — and fix it.

### Prompt
```
You are an expert in Applicant Tracking Systems (ATS) and resume optimization. Analyze this resume as if you were an ATS scanning for a specific role.

TARGET ROLE: [Job title you're applying for]

JOB DESCRIPTION (optional but recommended):
[Paste job description if available]

RESUME:
[Paste your full resume]

Perform a comprehensive ATS analysis:

1. ATS COMPATIBILITY SCORE (1-100):
- Overall score with explanation
- Break down by: keywords, format, content structure

2. FORMAT ISSUES:
- Any elements that ATS can't read (tables, columns, headers, graphics)
- File format recommendations
- Section heading issues

3. KEYWORD ANALYSIS:
- Keywords found in your resume that match typical [TARGET ROLE] requirements
- Critical keywords MISSING that you should add
- Keyword density issues (over-stuffed or under-optimized)

4. CONTENT ISSUES:
- Bullet points that are task-focused instead of achievement-focused
- Missing quantification opportunities
- Vague language that should be specific

5. RED FLAGS:
- Anything that might trigger automatic rejection
- Employment gaps, job hopping, missing info

6. SPECIFIC FIXES (prioritized):
- Top 5 changes that will have biggest impact
- Exact rewrites for problematic sections

Provide actionable, specific feedback. Don't just identify problems — show me how to fix them.
```

### Tips for Buyers
- Always include a job description for best results
- Run this before EVERY job application (keywords change)
- Fix the top 5 issues before applying

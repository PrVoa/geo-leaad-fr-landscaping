## Prompt 1: ATS Resume Scanner

Copy this into ChatGPT:

```
Act as an ATS (Applicant Tracking System). Analyze this resume for a [JOB TITLE] position.

Score it 1-100 based on:
- Keyword match with typical job descriptions
- Format compatibility
- Clarity of achievements
- Red flags that trigger rejection

Resume:
[PASTE YOUR RESUME]

Provide:
1. Overall score
2. Top 3 critical issues
3. Specific fixes with examples
```

**Pro tip:** Run this for each job you apply to. Different roles = different keywords.

---

## Prompt 2: Achievement Quantifier

Most resumes list **tasks**, not **achievements**. Big mistake.

```
Transform these job responsibilities into quantified achievements:

[PASTE YOUR BULLET POINTS]

For each one:
1. Ask clarifying questions if needed
2. Rewrite using format: "[Action verb] + [specific task] + [quantified result] + [context]"

Example output: "Reduced customer complaint response time by 40% by implementing automated ticket routing, handling 500+ tickets monthly."
```

**Why this works:** Recruiters skim. Numbers catch eyes.

---

## Prompt 3: Keyword Extractor

```
Analyze these 3 job descriptions for [JOB TITLE] roles:

[PASTE 3 JOB DESCRIPTIONS]

Extract:
1. Top 15 keywords that appear repeatedly
2. Must-have skills (80%+ of listings)
3. Nice-to-have skills (40-80%)
4. Action verbs they use

Format as a checklist I can use to audit my resume.
```

**Use this to:** Make sure your resume speaks the language of your target jobs.

---

## Prompt 4: Resume Summary Generator

Your summary is prime real estate. Most people waste it.

```
Write 3 professional summary options for my resume:

Target role: [JOB TITLE]
Experience: [X] years in [FIELD]
Top achievements: [LIST 2-3]
What makes me different: [YOUR UNIQUE VALUE]

Version 1: Traditional/corporate
Version 2: Results-focused
Version 3: Story-driven

Each should be 3-4 sentences max.
```

---

## Prompt 5: Quick Cover Letter

```
Write a cover letter for:

Job: [TITLE] at [COMPANY]
Why I'm interested: [ONE SENTENCE]
My relevant win: [YOUR BEST ACHIEVEMENT]

Requirements:
- Under 200 words
- Shows I understand their business
- Proves I can deliver results
- Ends with clear call to action

Tone: Professional but not robotic.
```

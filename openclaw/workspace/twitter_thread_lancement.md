## Thread Version 2 — "Pourquoi tes prompts IA sont nuls"

### Tweet 1 (Hook)
90% des gens utilisent ChatGPT comme ça :

"Écris-moi un email"

Et ils s'étonnent que le résultat soit générique.

Voici comment obtenir des outputs 10x meilleurs :

🧵

### Tweet 2
Le problème : tu donnes une instruction.

L'IA te donne une réponse moyenne.

La solution : donner un CONTEXTE + CONTRAINTES + FORMAT.

### Tweet 3
Exemple concret.

❌ Avant :
"Écris un post LinkedIn sur la productivité"

✅ Après :
"Tu es un copywriter LinkedIn expert. Écris un post sur la productivité pour des solopreneurs. Hook contre-intuitif. 150 mots max. Phrases courtes. CTA question ouverte."

### Tweet 4
La différence ?

- Rôle défini (expert)
- Audience précise (solopreneurs)
- Style spécifié (contre-intuitif)
- Contraintes claires (150 mots, phrases courtes)
- Format attendu (CTA question)

L'IA a tout pour performer.

### Tweet 5
Autre exemple.

❌ "Analyse ces données"

✅ "Tu es un data analyst senior. Voici un dataset. Identifie 3 patterns principaux avec % précis. Liste les anomalies. Donne 3 recommandations business actionnables. Format bullet points."

### Tweet 6
Framework universel :

1. RÔLE : "Tu es un [expert en X]"
2. CONTEXTE : "Pour [audience], dans [situation]"
3. TÂCHE : "Fais [action précise]"
4. CONTRAINTES : "En respectant [limites]"
5. FORMAT : "Présente sous forme de [structure]"

### Tweet 7
Applique ce framework à tous tes prompts.

Résultats garantis :
- Outputs plus précis
- Moins de reformulations
- Temps gagné
- Qualité pro

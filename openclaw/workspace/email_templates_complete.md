# SECTION 1: COLD OUTREACH TEMPLATES

## Template 1.1: The Value-First Approach
```
Subject: Quick idea for [Company Name]

Hi [First Name],

I came across [Company Name] while researching [industry] companies, 
and I noticed [specific observation about their business/website/content].

I've been helping [similar companies/roles] with [specific service], 
and had an idea that might help with [specific problem/opportunity].

[1-2 sentences about the idea or approach]

Would you be open to a 15-minute chat to see if this could work for you?

Either way, [genuine compliment about their work].

Best,
[Your Name]
[One-line credential]
```

# SECTION 3: CLIENT ONBOARDING

## Template 3.1: Welcome Email (After Contract Signed)
```
Subject: Welcome to [Your Business Name] — Let's get started! 🎉

Hi [Client Name],

I'm so excited to work with you on [project name]!

Here's what happens next:

1. **Kick-off Call** — I'll send a calendar link for us to align 
   on goals, timeline, and deliverables.

2. **Access & Materials** — Please send me:
   - [List what you need from them]
   - [Brand assets, logins, etc.]

3. **Communication** — I'll send weekly updates on [day]. 
   Best way to reach me: [preferred method]

4. **Timeline** — Our target completion is [date]. I'll keep 
   you posted on progress.

If you have any questions, just reply to this email.

Looking forward to creating something great together!

[Your Name]
```

## Template 3.2: Kickoff Meeting Agenda
```

Hi [Client Name],

1. Project goals & success metrics (10 min)

4. Communication preferences (5 min)
5. Questions & next steps (5 min)

If there's anything else you want to discuss, let me know!

See you soon,
[Your Name]
```

# SECTION 8: TRICKY SITUATIONS

## Template 8.1: Scope Creep Response
```
Subject: RE: [Their request]

Hi [Client Name],

Thanks for sharing this idea — I can see how [requested change] 
would add value.

This falls outside the current project scope, but I'd be happy 
to help with it.

Here are our options:

1. **Add it to this project:** Additional [cost/time estimate]
2. **Tackle it as a follow-up:** We finish current scope, 
   then handle this as a separate project
3. **Swap it in:** If we remove [existing deliverable], we 
   can add this instead

Which works best for you?

[Your Name]
```

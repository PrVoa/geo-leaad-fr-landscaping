## TEMPLATE STRUCTURE

### 📊 1. APPLICATION TRACKER (Main Database)
**Properties:**
| Property | Type | Purpose |
|----------|------|---------|
| Company Name | Title | Main identifier |
| Position | Text | Job title applied for |
| Location | Select | Remote / Hybrid / On-site + City |
| Salary Range | Text | Expected compensation |
| Application Date | Date | When applied |
| Source | Select | LinkedIn / Indeed / Company Site / Referral / Other |
| Status | Select | Wishlist / Applied / Phone Screen / Interview 1 / Interview 2 / Final Round / Offer / Rejected / Ghosted |
| Priority | Select | Dream Job / Good Fit / Backup / Practice |
| Job Posting URL | URL | Link to original listing |
| Contact Name | Text | Recruiter/Hiring manager |
| Contact Email | Email | For follow-ups |
| Resume Version | Select | v1 / v2 / Custom |
| Cover Letter | Checkbox | Sent? |
| Follow-up Date | Date | When to follow up |
| Notes | Text | Interview notes, impressions |
| Outcome | Text | Offer details or rejection reason |

**Views:**
1. **Kanban by Status** - Visual pipeline
2. **Calendar** - Deadlines and follow-ups
3. **Table** - All applications detail
4. **Gallery** - Company cards

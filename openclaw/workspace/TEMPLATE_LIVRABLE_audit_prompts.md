Utilisez cette structure pour tous vos futurs prompts :

```
## RÔLE
Tu es [expert/spécialiste] en [domaine].

## CONTEXTE
[Situation, background, contraintes business]

## TÂCHE
[Action précise à accomplir]

## FORMAT DE SORTIE
[Structure exacte attendue : bullet points, tableau, paragraphes, longueur...]

## CONTRAINTES
- [Contrainte 1 : ton, style]
- [Contrainte 2 : longueur]
- [Contrainte 3 : ce qu'il faut éviter]

## EXEMPLES (optionnel)
[Bon exemple de ce que vous voulez]
[Mauvais exemple à éviter]
```

# 📚 Guide "Prompt Mastery Basics"

## Les 5 erreurs fatales
1. **Prompts trop vagues** → Ajoutez contexte + contraintes
2. **Pas de format demandé** → L'IA devine, vous perdez
3. **Instructions négatives** → Dites ce que vous VOULEZ, pas ce que vous ne voulez pas
4. **Prompts trop longs d'un coup** → Découpez en étapes
5. **Pas d'itération** → Le premier output est un draft, affinez

## Les 5 boosters rapides
1. **"Tu es un expert en..."** → Active un "mode" spécialisé
2. **"Étape par étape"** → Force le raisonnement structuré
3. **"Format : ..."** → Obtenez exactement ce que vous voulez
4. **"Exemple : ..."** → L'IA comprend par l'exemple
5. **"Avant de répondre, pose-moi 3 questions"** → Améliore la pertinence

## Thread 1 : Hook + Value (Lancement initial)

### Tweet 1 (Hook)

### Tweet 2
L'erreur #1 : Demander sans contexte.

❌ "Écris un article sur le marketing"

✅ "Tu es un expert marketing B2B avec 15 ans d'XP. Écris un article de 1500 mots sur le cold email, avec 5 exemples concrets et un ton direct."

Le contexte = la qualité de l'output.

### Tweet 3
L'erreur #2 : Un prompt = une tâche.

Les pros utilisent des "mega-prompts" qui:
- Définissent le rôle
- Donnent le contexte
- Spécifient le format
- Ajoutent des contraintes
- Demandent des exemples

Un prompt de 200 mots > 10 prompts de 20 mots.

### Tweet 4
L'erreur #3 : Jamais de feedback loop.

Après le premier output :
"C'est bien, mais rends le ton plus punchy, ajoute des statistiques, et raccourcis les paragraphes."

L'IA s'améliore avec vos retours. Utilisez-les.

### Tweet 5
L'erreur #4 : Ignorer les frameworks.

Quelques-uns qui changent tout :
- Chain-of-thought : "Réfléchis étape par étape"
- Few-shot : Donnez 2-3 exemples de ce que vous voulez
- Role-based : "Tu es un [expert] qui [fait X]"

Ces 3 lignes ajoutées = output pro.

### Tweet 6
L'erreur #5 : Copier-coller sans adapter.

Un prompt viral sur Twitter ≠ bon pour VOTRE cas.

Les meilleurs prompts sont :
- Testés sur VOTRE use case
- Itérés 5-10 fois
- Documentés (vous savez pourquoi ça marche)
